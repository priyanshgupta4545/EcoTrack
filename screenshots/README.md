# EcoTrack UI Visual Showcase 📸

This directory stores screenshots and UI mock captures of the EcoTrack web platform for hackathon presentations, submission portals, and documentation.

### Included Views:
1. `01_dashboard.png` - Home Dashboard with KPI statistics cards, EcoScore showcase, quick-logger, and community benchmark leaderboard.
2. `02_activity_tracker.png` - Activity Tracker with calibrated habit presets, custom logger, ledger search, and filters.
3. `03_impact_calculator.png` - Environmental Impact Calculator with interactive lifestyle what-if sliders and equivalencies.
4. `04_challenges.png` - Active and catalog sustainability sprints with progress bars and milestone logging.
5. `05_achievements.png` - Tiered badge showcase (Bronze, Silver, Gold, Platinum) with dynamic unlock criteria.
6. `06_daily_tips_recycling.png` - Daily rotating tips and searchable "Can I Recycle This?" interactive lookup engine.
7. `07_reports_analytics.png` - Plotly interactive charts, cumulative carbon curve, weekly energy breakdown, and CSV/JSON export.
